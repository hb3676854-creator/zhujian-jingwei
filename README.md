# 竹间经纬 · 非遗竹编体验平台

一个以非遗竹编为主题的在线体验网站，包含四个页面：

- **首页** —— 竹编工艺与器物故事
- **创作工坊** —— 竹编纹样在线创作
- **素材工坊** —— 纹样素材库与跟做教程
- **我的作品** —— 本地保存的创作结果

## 在线访问

网站已通过 GitHub Pages 发布，直接用浏览器打开即可使用，无需安装任何东西：

**https://hb3676854-creator.github.io/zhujian-jingwei/**

## 使用说明

- 仅需现代浏览器，无需注册、无需后端服务
- 作品保存在浏览器本地（localStorage），换设备或清理浏览器数据后不会同步
- 建议使用桌面端 Chrome / Edge 访问，工坊页交互效果最佳
